# Seeded synthetic scenario fixtures

These three example folders were generated by `backend/app/synthetic.py` with seed `13013`. They are all synthetic and are provided as inspectable fixtures; use the application’s **Database & investigations → Synthetic data generation** page to generate, preview, download, import, or reset new seed variations.

Each folder contains a metadata JSON file and multiple log files. Records include cross-source identifiers, timestamp differences, clock corrections, and deliberate malformed or missing-time rows. Do not treat any finding as a real incident.
